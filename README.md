# Gowsic's Digital Canvas

Personal developer portfolio built to present my projects, technical skills, and development work in a clean, responsive interface.

## Overview

This portfolio highlights my work across frontend development, full-stack applications, backend APIs, and AI-assisted projects. It is built with a modern React and TypeScript stack and deployed on Vercel.

## Live Demo

https://gowsic-s-digital-canvas-main.vercel.app

## Tech Stack

- React
- TypeScript
- TanStack Start
- TanStack Router
- Vite
- Tailwind CSS
- Radix UI
- Framer Motion
- Vercel/Nitro deployment configuration

## Features

- Responsive portfolio layout
- Project showcase sections
- Modern UI components
- Smooth animation and interaction patterns
- Deployment-ready frontend configuration

## Project Structure

```text
src/
  assets/       Static assets
  components/   Reusable UI components
  hooks/        Custom React hooks
  lib/          Shared utilities
  routes/       TanStack file-based routes
```

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Security Note

Real environment variables should never be committed. Keep local secrets in `.env` and commit only safe examples in `.env.example`.
